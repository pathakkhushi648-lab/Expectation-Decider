Expectation Decider Project

Project Overview

The Expectation Decider project is a probability and statistical analysis project developed using Python and Google Colab. The objective of this project is to analyze student academic performance data and identify the probability of students passing the final examination based on factors such as study hours, attendance percentage, previous test scores, and participation in group discussions.

The project applies important probability concepts including empirical probability, theoretical probability, conditional probability, joint probability, marginal probability, random variables, probability distributions, Bayes’ theorem, and correlation analysis. Different graphical visualizations are used to understand relationships and trends within the dataset.

This project demonstrates how probability and statistics can be applied in educational analytics and decision-making systems.


Objectives

The main objectives of this project are:

* To analyze student academic performance using probability concepts
* To calculate probabilities related to student passing behavior
* To understand relationships between attendance, study hours, and exam performance
* To apply Bayes’ theorem for conditional probability analysis
* To visualize statistical relationships using graphs and charts
* To demonstrate practical implementation of probability in real-world datasets
